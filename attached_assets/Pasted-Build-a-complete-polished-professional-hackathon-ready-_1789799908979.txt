==================================================
CRITICAL API SECURITY REQUIREMENT
=================================

The Gemini API key MUST NEVER be exposed to the browser.

Never place:

GEMINI_API_KEY

inside:

* React client code
* browser JavaScript
* HTML
* public files
* GitHub source files
* README
* visible configuration
* hardcoded strings
* URLs
* frontend environment variables

Use Google AI Studio's secure server-side Secrets functionality.

Use the Gemini API only through server-side functionality.

The client should communicate with our server-side AI endpoint.

Never expose the raw API key in responses, logs, errors, UI, or source code.

If an environment variable is required, use:

GEMINI_API_KEY

only on the server side.

Make sure the generated project follows Google AI Studio's recommended server-side secret approach.
